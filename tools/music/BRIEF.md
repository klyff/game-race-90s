# Music brief — 10 original race beds

Please write **10 original instrumental tracks**. No vocals. No existing Kiss, Black Sabbath, or other catalog riffs — same *energy* and *era*, new songs.

## Style

- 1970s–80s hard rock / proto-metal / punk-metal
- Kiss stadium stomp + Black Sabbath low riff, with a punk-rock rush
- Big distorted guitar, driving drums, audible bass
- Arcade combat-racing, not a ballad and not modern djent
- Loop-friendly: a clear 8- or 16-bar hook that can repeat forever

## Use

These are **background beds** for the title and the races.

- Mix them so they sit under a shouted announcer
- We play them at **50% game volume**
- The player can mute with **M** / pause **AUDIO OFF**
- One track is picked at random per screen (title or race)

Today the game only has two procedural entrance pieces (title riff + guitar sting). These 10 recorded beds become the random pool.

## Specs

- Format: MP3, stereo, 44.1 kHz
- Length: 60–90 seconds, seamless loop (first bar matches last bar)
- No vocals, no speech, no copyrighted melody
- Peak below 0 dB; leave headroom — we play at 50%
- Instrumental only

When a file is in that folder, boot loads it and it joins the random pool. Missing files keep the old procedural riff.
